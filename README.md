# Disburzo Mini

A small React project that copies the main ideas of Disburzo, a lending management app.

## Features

- Sidebar layout with a dashboard
- Customers and Loans tables with search and filter
- Add and Edit customer form with validation
- Role switch (Admin, Area Manager, Branch Manager, Employee)
- Role-based menu and Add/Edit/Delete permissions
- React Router for page URLs
- Data saved in localStorage
- Responsive layout for phones

## Tech

React (Vite), React Router, plain CSS

## Run

npm install
npm run dev
